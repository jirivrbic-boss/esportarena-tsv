1) CO JE TO ZA APLIKACI
--------------------------------------------------------------------------------
Marketingový a registrační web studentského esport turnaje „ESPORTARENA TSV“ (Sezóna 4).
Podporuje více her v jedné sezóně: Counter-Strike 2 (CS2), Brawl Stars, League of Legends,
EA SPORTS FC 26.

Hlavní funkce:
  • Veřejná prezentace (hero, prize pool, roadmap turnaje, galerie, Twitch, síň slávy).
  • Registrace kapitánů přes Firebase Auth (e-mail + heslo).
  • Profil kapitána ve Firestore (`users/{uid}`) — doplnění osobních údajů, dokumentů.
  • Registrace týmů (`teams/{teamId}`) — soupiska, škola, Discord, Faceit u CS2, upload
    studentských průkazů / souhlasů rodičů do Firebase Storage.
  • Workflow schválení týmu administrátorem: pending → approved / rejected.
  • Po schválení může kapitán přihlásit schválený tým k konkrétnímu turnaji
    (`tournaments/{tid}/registrations/{teamId}`).
  • Oznamovací sekce (announcements) s kategoriemi podle her + obecné.
  • CMS editovatelný obsah domovské stránky, pravidel a úvodu oznámení (Firestore
    dokumenty pod `page_content/{slug}`).
  • „Hledám tým / hráče“ (LFG / free agents) — nástěnka + GDPR cron na úklid starých záznamů.
  • Notifikace: Discord webhooky, e-maily přes Resend (kapitán i admin alerty).
  • Faceit API: stažení ELO pro CS2 nicky (nasazení / férovost).

2) TECHNOLOGICKÝ STACK
--------------------------------------------------------------------------------
  • Next.js 16 (App Router), React 19, TypeScript
  • Tailwind CSS v4
  • Firebase: Auth (klient), Firestore, Storage (klient pro upload)
  • Server: firebase-admin tam, kde běží Node s plným SDK; paralelně REST API přístup
    k Firestore přes Google OAuth JWT (`jose`) — soubor lib/firebase/firestore-rest-admin.ts
    (vhodné pro prostředí bez klasického Admin SDK, např. některé edge/worker scénáře).
  • E-maily: Resend (npm balíček resend)
  • Animace: framer-motion
  • Deploy: primárně dokumentován Netlify (@netlify/plugin-nextjs, OpenNext); v package.json
    jsou také skripty pro Cloudflare (opennextjs-cloudflare, wrangler) — alternativní cesta.

4) AUTENTIZACE A ROLE
--------------------------------------------------------------------------------
Klient:
  • Firebase Auth — email/password.
  • contexts/auth-context.tsx: při změně uživatele načítá profil z Firestore `users/{uid}`,
    při registraci vytvoří dokument uživatele a volitelně welcome e-mail + notifikaci adminovi.

Server/API:
  • Ověření Identity: Authorization: Bearer <Firebase ID token>
    — lib/firebase/verify-client-id-token.ts (volá Admin verifyIdToken pokud je k dispozici SA).

Admin oprávnění:
  • Super Admin: jeden natvrdo definovaný e-mail v lib/super-admin.ts (SUPER_ADMIN_EMAIL).
  • Další admini: proměnná prostředí ADMIN_EMAILS (čárkou oddělené e-maily, server).
  • Klient musí znát stejný seznam pro navigaci na /admin: NEXT_PUBLIC_ADMIN_EMAILS
    (viz lib/admin-client.ts — musí být synchronizované s ADMIN_EMAILS).

Session cookie:
  • app/api/auth/session/route.ts — na Cloudflare Workers explicitně neukládá HttpOnly cookie
    (vrací session_cookie_skipped); DELETE stále maže cookie jménem firebase_session.
  • Starší komentáře v kódu odkazují na Edge middleware pro /admin — v repu middleware.ts
    aktuálně není; ochrana admin CMS stránek je přes CmsEditGuard + klientské přesměrování
    a API vyžaduje Bearer token.

Dočasný admin náhled:
  • Cookie admin_temp z /admin-docasny-pristup + env ADMIN_DOCASNY_TOKEN nebo
    ADMIN_DOCASNY_JEN_CESTA.

5) DATOVÝ MODEL (Firestore — logické kolekce)
--------------------------------------------------------------------------------
users/{uid}
  • CaptainProfile — e-mail, jméno, telefon, Discord, Faceit, Steam, isAdult, odkazy na
    soubory ve Storage (studentCertUrl, parentConsentUrl), profileComplete, časové razítka.

teams/{teamId}
  • TeamDocument — captainId, gameId (cs2|brawl_stars|lol|fc26), škola (zkratka + plný název),
    název týmu, status pending|approved|rejected, Faceit hub URL, soupiska (kapitán jako hráč,
    spoluhráči, náhradníci), trenér, e-mail a Discord kapitána, storageMeta[] pro GDPR úklid.

tournaments/{tournamentId}
  • TournamentDocument — název, gameId, volitelné pozadí a startsAt, prizePoolText, rulesText,
    faceitUrl, published, časové razítka.

tournaments/{tournamentId}/registrations/{teamId}
  • TournamentRegistrationDocument — teamName, schoolName, captainId, gameId, registeredAt.

announcements (nebo ekvivalentní kolekce oznámení — názvy v kódu app/api/admin/announcements)
  • title, content, imageUrl, authorName, category (cs2, lol, brawl_stars, fc26, general), …

page_content/{slug}
  • slug hodnoty: home | pravidla | oznameni — CMS patch nad výchozími hodnotami v lib/cms-defaults.ts

free agents / LFG
  • Dokumenty pro nástěnku „hledám“; cron maže staré záznamy (viz api/cron/cleanup-lfg).

6) FIREBASE STORAGE
--------------------------------------------------------------------------------
  • Prefixy users/{uid}/... a teams/{teamId}/... — upload z klienta (lib/storage-upload.ts).
  • Typ souborů: obrázky a PDF (oprava content-type pro Safari).
  • teams.storageMeta a GDPR cron: api/cron/cleanup-storage maže soubory starší 48 hodin
    a synchronizuje metadata v dokumentech týmů.
